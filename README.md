# Mohamed Saher - Portfolio Website

A professional, high-end animated UI/UX portfolio website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## 🎨 Features

- **Modern Design System**: Clean, minimal aesthetic with professional blue/gray color palette
- **Dark/Light Mode**: Smooth theme switching with system preference detection
- **Responsive Design**: Mobile-first approach with breakpoints at 320px, 640px, 1024px, 1280px
- **Smooth Animations**: Purposeful micro-interactions using Framer Motion (200-400ms duration)
- **Accessibility Compliant**: WCAG 2.1 AA standards with keyboard navigation and screen reader support
- **Performance Optimized**: Fast loading times, 60fps animations, lazy loading
- **8pt Grid System**: Consistent spacing and layout structure
- **SEO Friendly**: Proper meta tags, semantic HTML, and optimized structure

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Fonts**: Inter (body), Poppins (display)

## 📋 Sections

1. **Hero Section**: Animated text reveal with call-to-action buttons
2. **About Section**: Two-column layout showcasing experience and expertise
3. **Skills & Tools**: Grid-based presentation of core competencies and software proficiency
4. **Case Studies**: 4 detailed project showcases with problem, solution, process, and results
5. **Design Principles**: Core design philosophy and fundamental beliefs
6. **Contact Section**: Functional form with validation and social links

## 🛠️ Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd <project-directory>
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📦 Build

To create a production build:

```bash
npm run build
npm start
```

## 🎯 Design Principles

- **Visual Hierarchy**: Intentional scale, contrast, and positioning
- **Consistency**: Uniform patterns and interactions
- **Accessibility**: WCAG compliance and inclusive design
- **Grid Systems**: 8pt grid for harmony and scalability
- **White Space**: Breathing room to reduce cognitive load
- **Usability-First**: Function-driven beauty

## ♿ Accessibility Features

- Semantic HTML structure
- Proper heading hierarchy (H1-H6)
- ARIA labels and roles
- Keyboard navigation support
- Color contrast ratios ≥4.5:1
- Focus states for interactive elements
- Skip links for screen readers
- `prefers-reduced-motion` support

## 📱 Responsive Breakpoints

- Mobile: 320px
- Small: 640px (sm)
- Medium: 1024px (md/lg)
- Large: 1280px (xl)

## 🔧 Customization

### Updating Content

- Edit `components/*.tsx` files to modify section content
- Update `tailwind.config.ts` for design system changes
- Modify `app/globals.css` for global styles
- Change fonts in `app/layout.tsx`

### Environment Variables

Create a `.env.local` file for any environment-specific configurations.
